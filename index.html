Projects

DocOps

Document Q&A with a full LLMOps layer

Upload a PDF and ask it questions. The chat app is deliberately simple; the real work is the layer around it. Every answer is scored automatically with RAGAS, each configuration change is tracked as a named experiment in LangSmith, and every push to the main branch runs a regression evaluation in GitHub Actions that fails the build if quality drops below a threshold. A monitoring dashboard shows how the system performs over time.

The baseline run scored 93% faithfulness on a test paper. I built it on free-tier quotas, so the live CI run is a one-question smoke test, and the full 30-question evaluation set is ready for a paid tier.

AI Video Summarizer

Live app, deployed and free to try

Paste a YouTube link and get a description, key takeaways and suggested questions. Then ask follow-up questions that are answered from the video’s transcript, with conversation memory.

Each video is summarized only once and cached in Postgres. The backend keeps no state between requests and rebuilds chat history from the database, so it survives restarts on free hosting.
